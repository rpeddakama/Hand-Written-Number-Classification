# Hand-Written-Number-Classification

The code above was created in Jupyter Notebook using Python. It implements a 3 layer (3 nodes per layar) neural network to classify handwritten images of numbers from the MNIST NUMBERS dataset in a range of 0-9. The dataset consists of 60,000 training examples and 10,000 test examples. It is a feed forward network with backpropagation used as its training method. The final model has a accuracy of about 94 percent. Numpy used for matrix multiplication and scipy used for sigmoid function.
